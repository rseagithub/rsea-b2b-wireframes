Value Add Management

Manage embroidery, heat press, and screen printing configurations for Dawson Electrical

Custom module Build noteValue add management is a fully custom module. Allows admin users to create product customisation designs (embroidery, heat press, screen printing) that go through an approval workflow before being available for purchase. Each design is linked to a base garment type and includes positions, colours, and graphic/text customisations. Approved designs sync to ERP and become available in company catalogues.Custom: value_add_management + ERP sync + New value add

Approval workflow Logic noteWorkflow states: Draft → User Approved (admin confirms design) → RSEA Review (RSEA QC team checks print/embroidery feasibility) → Published (synced to ERP, available in catalogues). Rejected designs return to draft with a reason from RSEA QC. Admin can revise and resubmit. Each state change triggers a notification email.Custom: value_add_approval_workflow ERP sync Logic notePublished value adds are synced to ERP for production reference. The ERP system stores the full design specification including base garment, customisations, colour codes, and graphic files.
