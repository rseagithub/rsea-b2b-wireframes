Two address types Build noteAddresses come from two sources. ERP-synced addresses are pushed from the customer's ERP system and are read-only on the e-commerce platform — they cannot be edited or deleted by the user. User-created addresses are managed directly on the platform and can be freely edited or removed. Both types are available during checkout for delivery selection.Magento: B2B Company → company_addresses + ERP sync API

ERP sync Logic noteERP addresses are synced via API integration. They appear in the address book as read-only entries. The user can view them but cannot edit, delete, or change the default assignment. Changes to ERP addresses must be made in the source ERP system and will sync back to the platform. ERP addresses display a reference ID for traceability.Custom: ERP address sync API → Magento company_addresses Default addresses Logic noteDefault billing and shipping addresses are set at the ERP level and cannot be changed by the user on the platform. During checkout, users can select any address (ERP or user-created) for delivery, but the billing address defaults to the ERP-designated billing address. User-created addresses can be set as preferred delivery addresses per site.Magento: B2B Company → default_billing / default_shipping Checkout integration Logic noteBoth ERP and user-created addresses appear in the checkout address selector. Multi-address delivery split can use any combination of addresses. New addresses can also be created during checkout (these become user-created addresses).Magento: Checkout → address_selector + Multishipping
