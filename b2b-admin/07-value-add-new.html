Select customisation type

Type optionsLogic noteEach type has different characteristics: Embroidery is thread-based (premium, durable, uses stitch count). Screen Printing uses ink (good for large graphics, requires colour separation). Heat Press uses vinyl transfer (cost-effective, fast). Each type prompts for different configuration options.Custom: customisation_type → config_options
🧵

Embroidery

Thread-based. Premium finish, highly durable. Best for logos and text on all garment types. Requires stitch count and thread colour specification.

🖨️

Screen Printing

Ink-based. Ideal for large graphics with bold colours. Best for tee-shirts, jackets. Requires colour separation and artwork preparation.

🔥

Heat Press

Vinyl transfer. Cost-effective, fast turnaround. Good for simple logos and text. Available for all garment types.
